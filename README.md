# Mood Meter

Emotional intelligence app based on the Yale Center for Emotional Intelligence "Mood Meter" model (RULER approach).

Supports **English**, **Русский**, **Қазақша**.

## Deploy to Vercel

### Option 1: Via GitHub (recommended)

1. Push this project to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import your repository — Vercel auto-detects Next.js and deploys

### Option 2: Via CLI

```bash
npm install
npm run dev         # test locally at http://localhost:3000
npx vercel          # deploy to Vercel
```

## Tech stack

- **Next.js 14** (App Router)
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **lucide-react**
